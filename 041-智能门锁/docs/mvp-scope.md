# MVP 交付范围

## 已完成并可自动验证

- 密码 HMAC 存储、虚位密码、三次失败锁定。
- RFC 6238 六位 TOTP 与时间窗口校验。
- 有效期和次数受限的访客码。
- 远程命令 HMAC、过期校验、单调请求号防重放。
- 自动落锁、防拆报警锁存、CRC 审计日志环。
- 门虚掩超时提醒、日志倒序读取、网络失败重试和显式诊断上报。
- 周期密码、胁迫密码/指纹以及可选的指纹/卡片加密码双重认证。
- FreeRTOS 静态任务/队列骨架和单一状态拥有者模型。
- Mosquitto + Node-RED 本地云端、登录保护、手机网页、远程锁控、访客码
  和紧急事件 HTTPS Webhook。
- 桌面 Debug/Release 测试与 Cortex-M3 交叉编译。

## 接板时完成

- 使用已配置的 `firmware/stm32/cubemx/SmartLock.ioc` 生成 CubeIDE 工程并
  实现 `board_port.h`；若成品 PCB 已经布线，则只调整与实物不一致的引脚。
- 联调 ZW101/AS608 指纹、RC522、键盘、OLED、DS3231、SG90、W25Q64、
  ESP8266 和门磁/防拆开关。
- 在 ESP8266 AT 固件能力允许的前提下启用 MQTT TLS；若其 TLS/证书能力
  不可靠，应更换 ESP32-C3 通信模块，而不是退回公网明文 MQTT。
- 进行断电恢复、Flash 磨损、弱网、看门狗、掉电锁态和整机功耗测试。
- 在板级实现中完成真实 STOP 进入、模块断电、PLL/UART DMA 恢复和触摸唤醒。

## 明确延后

- 多门锁/多租户、手机原生 App、云端数据库、OTA、智能家居平台联动。
- 活体指纹、安全元件、安全启动和任何金融/安防等级认证。

MVP 的验收标准是：指纹、卡片、主人密码、TOTP、访客码和周期密码在断网时
可用；远程命令不可伪造或重放；
断电/重启默认保持锁闭；日志可恢复；报警不能被普通认证解除。
