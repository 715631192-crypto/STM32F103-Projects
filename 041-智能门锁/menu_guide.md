# 管理菜单操作说明（2026-09-14 版）

待机界面按 **`D`** 进入管理菜单。首次进入需要**验证主密码**（出厂 `123456`）；
用**管理员指纹（48 号页）**或**管理卡**开锁后的 **30 秒内**按 `D` 可免验直达主菜单。
菜单/输入页 **30 秒**无操作自动退回待机（等手指/等卡片的页面 60 秒）。

## 按键约定（与参考工程 app_ui.c 一致）

| 键 | 菜单类页面 | 输入类页面 |
|---|---|---|
| `A` | 上移一项 | —（记录页=上翻一条） |
| `C` | 下移一项 | 退出本页 |
| `D` | 进入/确认 | — |
| `B` | 返回/退出 | 删除最后一位 |
| `#` | — | 确认提交 |
| `0~9` | — | 输入数字 |

## 菜单树

```
功能菜单
├─ 1 密码管理
│   ├─ 1 修改主密码（输原密码 → 新密码 → 再输一遍，落盘成功才算改好）
│   └─ 2 胁迫密码   （同上三步；不允许与主密码相同）
├─ 2 指纹管理
│   ├─ 1 录入指纹   （输编号 1~47 → 按两次手指）
│   ├─ 2 删除指纹   （输编号 1~49，# 删除）
│   └─ 3 管理员指纹 （固定 48 号页，按两次手指）
├─ 3 卡片管理
│   ├─ 1 添加卡片   （刷卡即登记）
│   ├─ 2 删除卡片   （刷哪张删哪张）
│   └─ 3 添加管理卡 （登记为管理员：开锁后 30 s 内可免验进菜单）
├─ 4 胁迫管理
│   ├─ 1 胁迫密码   （同"密码管理-胁迫密码"）
│   ├─ 2 录入胁迫指纹（固定 49 号页，按两次手指）
│   └─ 3 删除胁迫指纹（直接删 49 号页）
└─ 5 系统设置
    ├─ 1 修改时间   （输入 12 位 YYMMDDHHMMSS，例如 260914 175500 → 2026-09-14 17:55:00）
    ├─ 2 开锁记录   （A 上翻 / C 下翻 / B 退出；与待机页 A/B 翻日志同源）
    └─ 3 开锁组合   （0 关:单因子 / 1 指纹+密码 / 2 刷卡+密码，D 确认并落盘）
```

## 行为要点

- 所有改动（改密码、录指纹、卡片增删、开锁组合）都会**写审计日志**并要求
  `board_security_save()` 成功（CRC 信封落 W25Q64）后才算数，失败自动回滚。
- 指纹模板存在 **AS608 模块**里（1~47 普通 / 48 管理员 / 49 胁迫），
  擦 W25Q64 不会清掉指纹；删除要用菜单里的删除功能。
- 卡片的"管理员"角色存在卡片表条目的 flags 字节（位 0），旧卡片表无需迁移。
- **修改时间注意事项**：当前 `DS3231_USE_SOFT=1`（软 RTC，断电不保持），
  改的时间重启后回到编译时刻。输入的是北京时间，系统内部按 UTC 存
  （与 TOTP、云端时间轴一致），所以待机时钟显示比北京慢 8 小时是既有设计。
  等 DS3231 硬件到位后把 `DS3231_USE_SOFT` 改 0 即为真实时钟。
- 录入指纹/添卡删卡期间，后台的指纹识别与刷卡轮询会**整体让路**
  （读头互斥），不会互相打架；菜单退出后自动恢复。
- 菜单打开时不会进入 STOP 低功耗（否则键盘扫描停了）。

## 固件资源（本次改动后，Keil AC5）

- 优化从 Level 0 提到 **Level 2（-O2）**（`SmartLock.uvprojx`），否则 Flash 装不下。
- 关闭 `configUSE_TIMERS`（全工程无 xTimer 调用），省约 1.2 KB RAM。
- 实测：`Code=52416 RO-data=8100 RW-data=400 ZI-data=18208`，0 错 0 警；
  ROM 60916/65536（余 4620 B），RAM 18608/20480（余 1872 B）。
- 字库从 73 字扩到 **122 字**（+1568 B），其中 34 个字用 `.bak151` 的原厂字形
  还原（避免 TTF 重渲染差异）。
