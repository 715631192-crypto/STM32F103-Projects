# 038-机械臂：基于 STM32F103 的 6 轴舵机机械臂

## 项目背景

一套由 **PS2 手柄**无线遥控的 **6 自由度舵机机械臂**。下位机以 STM32F103 解析 PS2 指令，通过 **UART 总线舵机**控制 6 个（可扩展 8 个）舵机，配合 **OpenMV 视觉**做目标抓取，并提供 **QT（C++）上位机**做参数调试与动作编辑。

## 硬件组成

- 主控：STM32F103（72 MHz）
- 执行：6~8 路总线舵机（USART 异步半双工总线）
- 输入：PS2 无线手柄（GPIO 模拟 SPI 通信）
- 视觉：OpenMV 摄像头（串口下发坐标）
- 其他：WS2812B 彩灯（GPIO 时序）、W25Q64 Flash 存储、OLED

## 关键技术点

### 1. PS2 手柄（GPIO 模拟 SPI）
- 使用 **PA13 / PA14 / PA15**（默认 JTAG 引脚）作为 PS2 的 DAT / CMD / CLK，因此需对 **JTAG/SWD 引脚重映射**，释放这些引脚作普通 GPIO。
- `app_servo.c` 的 `parse_action()` 解析两类指令：
  - `#xxxPSCK±bbb!`：对某 ID 舵机做角度**偏差调节**（± 偏移量 `bbb`）。
  - `#xxxPDST!`：**原地停止**指令。

### 2. 总线舵机（USART1 / USART3）
- 舵机通过串口总线通信；新增 `uart1_mode = 5` 角度控制模式，协议格式 `S,ID,角度D`。
- 位置字节 = **角度 × 10**，便于以 0.1° 分辨率下发。

### 3. TIM2 分时复用 PWM
- 用 **TIM2 中断**实现时分复用：20 ms 周期 = 8 × 2.5 ms 时隙，每个时隙驱动一路舵机。
- 定时器预分频 **PSC = 71** → 计数精度 **1 µs/tick**。
- 脉宽**安全钳位 510 ~ 2490**（对应舵机行程，避免堵转/超程）。

### 4. 运动学
- **六自由度逆运动学**解算，由末端坐标反推各关节角度。

### 5. 其他
- **JTAG/SWD 重映射**：除 PA13/14/15 外，PB3/PB4 也参与重映射以释放更多引脚给外设。
- **W25Q64**：按 **256 B/组**存储动作序列。
- **QT 上位机**：C++/Qt 做动作编辑、监控与回放。

## 编译与运行

1. 工具：Keil MDK / EIDE，芯片 STM32F103，主频 72 MHz。
2. 注意：工程启用了 **SWJ 重映射**，下载调试请使用 **SWD（PA13/PA14 仍可作 SWDIO/SWCLK，但 PA15 已作普通 IO）** 或预留调试接口。
3. 上电后 PS2 手柄对码即可遥控；上位机通过串口下发动作序列到 W25Q64。
