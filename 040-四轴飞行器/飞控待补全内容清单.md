## 一、🔴 关键缺口（导致飞控无法正常姿态控制，必须补全）

### 1. `HAL/control.c` —— `FlightPidControl()` 的 `case PROCESS_31: //正式进入控制` 为空

- **位置**：`control.c` 第 299 ~ 303 行
- **现状**：该 `case` 内只有空行，没有任何代码。
- **铁证**：全工程 `pidUpdate(...)` 仅出现 **6 次**，全部在 `control.c` 内：
  - 高度环 2 次：`pidHeightHigh`(128行)、`pidHeightRate`(131行)
  - 光流环 4 次：`Flow_PosPid_y/x`(232/234行)、`Flow_SpeedPid_y/x`(241/243行)
  - **姿态环 6 个 PID（`pidRateX/Y/Z`、`pidPitch`、`pidRoll`、`pidYaw`）的 `pidUpdate` 调用次数为 0**。
- **连锁影响**：
  - 这 6 个 PID 的 `.measured` 从未被赋真实姿态/角速度值（仅 294 行解锁时 `pidYaw.measured=0` 归零一次）；
  - `MotorControl()`（364~367行）把 `pidRateX.out / pidRateY.out / pidRateZ.out` 分配到四个电机，而它们的 `.out` 永远是 0 → **姿态控制量恒为 0，飞行器无法自稳**。
- **调度确认**：`USER\scheduler.c` 的 `Duty_2ms()` 每 2ms 调用 `FlightPidControl(0.002f)`，但该函数空壳，等于姿态控制线程空转。

#### ✅ 补全方案（在原有 `case PROCESS_31` 内补全，不新增函数，符合「只改原有代码」约束）

将 `control.c` 第 299~303 行：

```c
		case PROCESS_31: //正式进入控制
			

		
			break;
```

替换为：

```c
		case PROCESS_31: //正式进入控制
		{
			//==== 外环：姿态角反馈（角度环）====
			pidPitch.measured = Angle.pitch;   // 俯仰角（来自 GetAngle）
			pidRoll.measured  = Angle.roll;    // 横滚角
			pidYaw.measured   = Angle.yaw;     // 偏航角

			pidUpdate(&pidPitch, dt);
			pidUpdate(&pidRoll,  dt);
			pidUpdate(&pidYaw,   dt);

			//==== 内环：角速度反馈（陀螺仪环）====
			// 注意：陀螺仪轴 ↔ 姿态轴的对应关系取决于 IMU 安装方向，
			//       以下为典型 X 型四轴约定，务必按实际机架核对，否则会反向！
			pidRateX.measured = Attitude.gyroY_IMU; // 俯仰角速度
			pidRateY.measured = Attitude.gyroX_IMU; // 横滚角速度
			pidRateZ.measured = Attitude.gyroZ_IMU; // 偏航角速度

			//==== 串级：外环输出作为内环期望 ====
			pidRateX.desired = pidPitch.out;
			pidRateY.desired = pidRoll.out;
			pidRateZ.desired = pidYaw.out;

			pidUpdate(&pidRateX, dt);
			pidUpdate(&pidRateY, dt);
			pidUpdate(&pidRateZ, dt);
		}
			break;
```

#### ⚠️ 补全后必须核对的 3 个点
1. **轴映射**：`gyroX/Y/Z` 与 `pidRateX/Y/Z` 的对应、以及和 `MotorControl` 电机分配（364~367行）是否一致，需按机架/IMU 安装方向逐项验证，调反会导致发散。
2. **量纲一致**：`Angle.pitch/roll/yaw` 与 `Mode_Controler()` 中 `pidPitch.desired = -(Remote.pitch-1500)*ratio` 的单位要统一（默认按「度」）；陀螺仪反馈也需与 PID 参数标度匹配（可用 `Attitude.gyroX_IMU` 已滤波值）。
3. **限幅**：`pidRateX/Y/Z` 的 `OutLimitHigh/Low` 需在 `INIT.c` 的 `pid_param_Init()` 里设定，否则内环输出可能越界。
