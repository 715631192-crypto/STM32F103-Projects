# 040-四轴飞行器：基于 STM32F103 的四轴飞行器飞控

## 项目背景

一套完整的 **四轴飞行器飞控 + 遥控端** 方案。飞控以 STM32F103 运行 **四元数姿态解算**与**串级 PID**，配合 **MPU6050** 六轴惯性单元与 **PMW3901 光流**实现定点悬停；遥控链路使用 **NRF24L01 2.4G**，遥控端程序独立置于 `遥控程序/`。

## 硬件组成（飞控）

- 主控：STM32F103（72 MHz，裸机前后台 + 轻量调度器）
- 姿态：MPU6050（I2C，六轴加速度/陀螺仪）
- 光流：PMW3901（SPI，地面速度估计，辅助定点）
- 通信：NRF24L01（SPI，2.4G 遥控链路）
- 输出：4 路无刷电调 PWM（**18 kHz / 1000 级**分辨率）
- 看门狗：IWDG（1 s 喂狗）

## 关键技术点

### 1. 姿态解算
- MPU6050 原始数据经 **四元数**更新（~**166 Hz** 解算频率），比欧拉角更稳定、无万向锁。
- 对陀螺仪/加速度计做 **卡尔曼滤波**，抑制噪声与漂移。

### 2. 控制律
- **串级 PID**：内环角速度环 + 外环角度环，油门范围 **0 ~ 900**。
- 输出 **18 kHz / 1000 级** PWM，提升电调响应线性度、降低啸叫。

### 3. 光流定点
- PMW3901（SPI）提供机体水平速度，闭环修正位置漂移。

### 4. 遥控链路
- NRF24L01（SPI）2.4G 双向通信；遥控端工程见 `遥控程序/`。

### 5. 可靠性
- **IWDG 独立看门狗** 1 s 喂狗，飞控异常时自动复位。

## 编译与运行

1. 工具：Keil MDK / EIDE，芯片 STM32F103，主频 72 MHz。
2. 库：STM32 标准外设库与 CMSIS（已随仓库）。
3. 烧录飞控程序到飞控板、遥控程序到遥控板；对频后解锁起飞。
4. 上位机可通过 ANO 数传（`HAL/ANO_Data_Transfer`）实时观测姿态与 PID 参数。
